# ATELIER BASIC

A static single-page storefront prototype built with semantic HTML, Tailwind CSS via CDN, custom CSS, and vanilla JavaScript.

## Run locally

```bash
python3 -m http.server 3000
```

Then open `http://localhost:3000`.

## GitHub Pages

Publish the repository root as the GitHub Pages source. No build step is required. Product imagery is loaded from Unsplash image URLs and can be replaced with local assets if desired.
